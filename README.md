# إيقاع | Iqaa

**إيقاع** مخطّط يومي يساعد على اختيار المهمة الملائمة لمستوى الطاقة الحالي. **Iqaa** is an energy-aware daily planner that helps users choose tasks that fit their current capacity.

## ما يتضمنه هذا الإصدار

- واجهة عربية RTL افتراضية مع التبديل إلى الإنجليزية، وخط Cairo/Inter عبر Google Fonts.
- مهام محلية محفوظة في Hive: إضافة وتعديل وحذف وإكمال، وصف، مدة، ومستوى طاقة.
- مقياس طاقة يومي من 1 إلى 5، واقتراح المهام المتوافقة مع طاقة المستخدم.
- تقدم اليوم، مؤقّت تركيز 25 دقيقة، تقارير أساسية برسم بياني، وثيم فاتح/داكن/النظام محفوظ محلياً.
- نسخ بيانات المهام بتنسيق JSON إلى الحافظة، حد مجاني 10 مهام نشطة، وصفحة عرض إيقاع بلس.
- ملفات Android وiOS الافتراضية المُنشأة بواسطة Flutter.

## التشغيل

تحتاج إلى Flutter حديث (Dart 3.2 أو أحدث) وAndroid Studio أو Xcode للمنصة المطلوبة.

```bash
flutter pub get
flutter run
```

يمكن بناء التطبيق بأوامر Flutter المعتادة، مثلاً:

```bash
flutter build apk
flutter build ios
```

لا يحتاج استخدام المهام والطاقة إلى اتصال بالإنترنت بعد تنزيل الحزم. الخطوط من Google Fonts قد تتطلب اتصالاً أول مرة حتى تُخزّن محلياً.

## توليد Hive adapters

التخزين الحالي يستخدم JSON داخل Hive ولا يتطلب مولد adapters. الحزم المطلوبة متضمنة، ويمكن تشغيل الأمر الآتي عند إدخال نماذج مولّدة لاحقاً:

```bash
dart run build_runner build --delete-conflicting-outputs
```

## RevenueCat والشراء

حزمة `purchases_flutter` مضافة وإذن الإنترنت موجود في Android، لكن **الشراء الفعلي غير موصل** في هذه النسخة. يلزم إدخال مفاتيح SDK العامة حسب المنصة، إعداد entitlement والمنتج الشهري والتجربة المجانية في RevenueCat ومتاجر التطبيقات، ثم تنفيذ تهيئة SDK واستدعاءات الشراء والاستعادة. لا تضع مفاتيح سرية في المستودع. زر الترقية الحالي يعرض مزايا الاشتراك ولا يجري عملية دفع.

## موارد المشروع

- `lib/main.dart` — التطبيق والواجهة والنموذج والتخزين المحلي.
- `android/` و`ios/` — ملفات المنصات القياسية التي أنشأها Flutter.
- `assets/images/iqaa_mark.svg` — علامة SVG بسيطة.
- `assets/fonts/` و`assets/sounds/` — مجلدان مخصصان لإضافة ملفات مرخّصة عند الحاجة.
- `pubspec.yaml` — الحزم المطلوبة، بما فيها الحزم التي طلبتها المواصفات.

## ملاحظات قبل النشر

هذا إصدار أولي للمصدر وليس إصدار متجر. اجتاز `flutter analyze` واختبار واجهة/تنقل واحد (`flutter test`). لم يُبنَ APK أو تطبيق iOS؛ لم تتوفر Android SDK أو بيئة Xcode في بيئة الإنشاء. إصدار `intl` في `pubspec.yaml` هو `^0.20.3` بدلاً من `^0.19.0` المطلوب في المواصفات، لأن إصدار Flutter الحالي يشترط `intl ^0.20.3` عبر `flutter_localizations`. إعداد RevenueCat الفعلي، التصدير إلى ملف قابل للمشاركة (بدلاً من النسخ إلى الحافظة)، التحليلات الأسبوعية الحقيقية، الإشعارات الصوتية، وإكمال نصوص المتاجر والتوقيع يتطلب إعدادات وبيانات منصة خاصة قبل الإطلاق.
